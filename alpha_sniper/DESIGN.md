# Alpha Sniper：币安非对称机会猎手

目标路径：`1000 USDT → 100000 USDT`，窗口 ≤ 180 天。  
场内：只做币安 **现货 / 1x 合约 / Alpha**。  
默认姿态：**蹲点、埋伏、空仓**。开火只发生在「这里有可能出现别人来不及反应的大涨或大跌」时。

---

## 0. 先把账算清楚（否则框架是自欺）

100 倍不是技术指标磨出来的。老老实实做均线、RSI、网格，期望是缓慢磨损。

一条还能说得通的路径：

| 路径 | 含义 | 系统怎么用 |
|---|---|---|
| 多次中等爆发 | 约 8–15 次「命中 2x–5x、打亏只丢 3–5% 本金」 | 主路径：高选择、紧止损、让利润跑 |
| 两次真正的肥尾 | 两次「20%–35% 仓位吃到 8x–20x」再叠加若干次 2x | 稀有：只在共振极强时放大 |
| 每天 2.6% | 数学上 180 天约 100x | **不做**。这是拥挤的短线，不是本系统 |

关键不等式（才有正期望）：

```
0.2 × (+60% 权益) + 0.8 × (-5% 权益)  >  0
```

也就是：**可以经常错，但不可以经常把错的做成深亏；对的必须拿到非线性。**  
若止损做成 -15% 权益、赢家只拿 +20%，数学上必爆。

本系统优化的是三件事，而不是「预测涨跌」：

1. **可能性**：这个标的 *有没有资格* 走出几十%、几倍（大盘、深流动性币没有这个资格）。
2. **点火**：沉寂之后，多路独立证据在短窗口同时亮起。
3. **活着**：棘轮锁盈、日亏损熔断、空仓是主状态。半年里 95% 的时间应该什么都不做。

100x 是肥尾结果，不是 KPI。框架按「最大化碰到肥尾且不被假突破清盘」来设计。

## 2. 核心思想：可能性曲面 × 沉寂后共振

大多数人问：「现在会不会涨？」  
我们先问：「**这里有没有资格出现别人来不及反应的大涨大跌？**」再问：「**现在是不是从沉寂切换成多路证据同时点火？**」

```
可能性高 × 刚点火 × 拥挤度低 × 还能退出 × BTC 环境允许
        → 才允许从「蹲点」变成「命题」
```

四个正交分数（缺一不可）：

| 分数 | 回答的问题 | 低分时 |
|---|---|---|
| Possibility | 流动性/体量是否允许 5x–50x | BTC/ETH 直接剔除出猎场 |
| Ignition | 是否刚从死寂被点燃 | 继续蹲 |
| Crowding | 是不是已经人人看见 | 禁止追高 |
| ExitLiquidity | 真拉起来后你卖给谁 | 没退出通道的「假 100x」直接丢弃 |

「别人发现不了」通常不是因为你多了一条神秘指标，而是：

- 他们盯着已经在动的币（拥挤）；
- 他们把同一类噪声当成 3 个信号（假共振）；
- 他们没有一张事先算好的埋伏表，点火后还在思考。

我们把思考提前到蹲点期：**点火那一秒钟只许执行，不许辩论。**

## 4. 猎场：负空间，不是热榜

热榜、涨幅榜、资金费率榜是拥挤的。猎场是从全市场 **减掉** 之后剩下的东西：

剔除：

- 稳定币、BTC、ETH、BNB 等不可能 10x 的深流动性资产（它们只做体制过滤，不当猎物）
- 7 日内已经大涨、社交拥挤的标的（你看到时别人也看到了）
- 只跟 BTC 呼吸、自身没有独立叙事的影子币
- 没有退出流动性的「纸面百倍」（买得进卖不出等于没赚到）

留下：

- 币安 **Alpha** 新币、小市值现货、窄盘
- 成交萎缩、波动被压扁、很久没出现 20% 波段的「缩簧」
- 同叙事里 **还没动** 的滞后币
- 解锁/团队充币后的潜在大跌（1x 空）

这张表叫 **Possibility Surface（可能性曲面）**。每天 95% 的扫描只是在更新这张表，而不是下单。

## 5. 缩簧表：埋伏发生在开火之前

对每个候选，蹲点期持续维护：

| 量 | 缩簧含义 |
|---|---|
| 近 7 日波动 / 近 30 日波动 | 被压扁 |
| 近 7 日量 / 近 90 日量 | 成交枯死 |
| 价格箱体相对 ATR | 弹簧压紧 |
| 距上次 20% 波段的天数 | 沉寂时钟 |
| 盘口厚度 / 日均量 | 真空：一点点主动流就能把价格打飞 |

缩簧分数高的币进入 **ARMED 预计算**：

- 做多还是做空的预案
- 用现货、Alpha 还是 1x
- 名义仓位、失效价、时间止损
- 分批兑现规则

**点火后禁止重新发明策略。** 来不及的本质是决策延迟，不是网速。

## 6. 传感器：找「别人还没定价的证据」

传感器只产出 **脉冲**，不直接下单。单独一个脉冲 = 噪音，忽略。

### 6.1 证据必须分族（防假共振）

同一族里 3 条量能指标一起响，仍算 1 票。必须跨族：

| 族 | 例子 | 它在证明什么 |
|---|---|---|
| `microstructure` | 量能真空、主动吃单毒性、盘口空洞 | 有人在用真金白银点火 |
| `catalyst` | Alpha 上币、公告、合约上架 | 有一个「故事可以开始」的开关 |
| `positioning` | 大额充币、聪明钱影子、持仓集中度变化 | 有知情者在搬筹码 |
| `narrative` | 同板块突然共振、滞后币尚未动 | 注意力正在迁移 |
| `calendar` | 解锁、周末/节假日流动性黑洞、Alpha 积分快照 | 时间本身就是催化剂 |

**开火条件：窗口内 ≥ 3 个独立族，且点火前缩簧/沉寂分数高。**

### 6.2 别人较少系统化的传感器

1. **沉寂后的突然一致（Silence → Coherence）**  
   先找「两到四周没人理」，再找短窗口内微观结构 + 催化剂 + 叙事同时亮。  
   大众扫描器只找「现在最吵的币」。吵 = 拥挤。

2. **点火分类：知情 vs 散户**  
   同样是放量：
   - 少量大单主动吃卖单一侧 → 更像知情，可跟
   - 无数碎单涌入 → 更像 FOMO，倾向不追或反向等衰竭  
   大多数量价策略不区分这两种放量。

3. **叙事滞后，不追龙头**  
   A 先动，B 同叙事仍在缩簧 → 埋伏 B。  
   追 A 是付冲击成本；B 才是时间差。

4. **Alpha 上币的两段式**  
   - 上币瞬间：只允许预先 ARMED 的标的，否则滑点吃掉优势  
   - 上币后抛物线衰竭：1x 空或现货离场，不接飞刀当多  
   很多人只做第一段，死在第二段。

5. **公告第二波，不当第一秒炮灰**  
   币安公告后前 30 秒是拥挤绞肉。更干净的是：相关滞后币、或第一波回踩缩簧再确认。  
   「更快」不是边缘，「更准的第二动作」才是。

6. **周末/时区流动性真空**  
   盘口极薄时，一笔中等主动流就能打出 20%+。仓位要更小，但盈亏比可以极大。  
   别人周末关掉机器人；我们把真空当成放大镜。

7. **大跌预案（1x 空）不是「从 ATH 回撤 20%」**  
   真空头共振：解锁日历 + 兑换所充币 + 抛物线量能衰竭。  
   缺其中两族，禁止空「叙事真启动」的第一回调。

8. **负空间热度**  
   不扫涨幅榜。扫「可能性高 ∩ 沉寂高 ∩ 今天突然多了一族证据」。

9. **中文/广场/韩语领先（接口位）**  
   同一则上币或叙事，中文广场、韩推经常早于英文 CT。传感器按语言通道独立计族。

10. **退出通道一票否决**  
    没有对手盘的百倍是幻象。Alpha 盘口过薄时，即使可能性再高也不许用大仓。

## 7. 命题（Thesis）：仓位不是方向，是一张会过期的假说

开仓 = 创建命题，必须能一句话说完：

> 「因 [独立族 A,B,C] 在沉寂后共振，赌 [SYMBOL] 在 [T] 小时内出现非对称 [涨/跌]；若价格回到 [失效] 或时间耗尽则假说死亡。」

| 字段 | 作用 |
|---|---|
| hypothesis | 人话假说 |
| sensors | 哪些族点燃了它 |
| invalidation | 假说死亡价 |
| time_stop | 假说过期（催化剂 36h，缩簧突破 12h，空头 24h） |
| scale_out | +40% 减 25%；+100% 再减 25%；其余用峰值回撤 25% 跟踪（给倍数留空间） |
| venue | 现货 / Alpha / 1x |

假说死了必须走。禁止「再等等也许回来」。那是网格思维，不是猎手思维。

## 8. 执行边界：现货、1x、Alpha

| 场景 | 通道 | 原因 |
|---|---|---|
| Alpha / 小币做多 | **现货或 Alpha 现货** | 1x 也会因标记价格乱跳被打穿；归零只亏本金 |
| 大跌做空 | **1x 逐仓合约** | 现货不能空；禁止 >1x |
| 普通现货做多 | 现货优先 | 简单、无清算 |
| 盘口极薄 | 缩小仓位或放弃 | 退出分数一票否决 |

1x 的意义不是放大，是 **获得空头权**，以及在部分合约上更干净的对冲。  
任何配置若尝试把杠杆写成 >1，风控层直接拒绝。

## 9. 风控总督：100x 的真正敌人是回吐和假突破

### 9.1 仓位

- 默认空仓。最多 **2** 个并发命题。
- 普通共振：名义 ≈ 权益的 8%–12%（1x）。
- 四族共振 + 可能性极高 + 拥挤极低：名义可到 22%–28%。这是「月亮仓」，一年碰不到几次。
- 单笔命题最大亏损 **≤ 权益 5%**（硬止损，不是心态）。
- 已经按计划兑现（减过仓且剩余 ≤ 55%）的命题 **不再占用新埋伏名额**，把子弹留给下一只猎物；剩余仓继续跟踪。

### 9.2 熔断

- 日亏 12%：当日停机，只许平仓。
- 周亏 25%：降到最小仓，强制复盘。
- BTC 24h < -6%：禁止新开多。

### 9.3 棘轮金库（防「20x 后又吐回 1x」）

权益每创出 2x 高水位（2k / 4k / 8k / 16k / 32k / 64k）：

- 把 **该段盈利的 15%** 锁进金库
- 金库不再用于新风险
- 其余继续打猎（否则锁太多到不了 100x）

大赢之后 48h 内 **禁止月亮仓**（只许普通仓或空仓）。赢家膨胀是回吐的主因。

亏损之后 **冷却**，禁止立刻加倍。禁止报复交易。

### 9.4 时间

不给假说无限生命。压缩突破若 12 小时还没有推进，大概率是假点火，走。

## 10. 复盘记忆：让共振权重长在真实肥尾上

每笔命题结束后写入：

- 当时亮起的独立族组合
- 可能性 / 拥挤 / 退出分数
- 之后 6h / 24h / 72h 的真实路径
- 是否出现过 ≥50%、≥100%、≥300% 的位移

评分器只提高「历史上真的走出肥尾」的组合权重，降低「经常假突破」的组合。  
冷启动用先验：`catalyst + microstructure + silence` 高于 `单量能三连`.

## 11. 主循环（实现逻辑）

```
每一根 bar（实盘 2–5s 报价 + 事件驱动；纸上 15m）：
  1. 拉快照（现货 / 1x 标记价 / Alpha）
  2. 更新 BTC 体制、可能性曲面、缩簧表
  3. 传感器 → 脉冲
  4. 共振引擎：跨族计数 + 沉寂前提
  5. 点火分类（知情 / FOMO）
  6. 叙事滞后匹配
  7. 评分：四分数 + 记忆加权
  8. 风控：并发、仓位、熔断、杠杆上限、金库
  9. 无持仓且通过 → 把预计算单变成命题并执行
 10. 管理已有命题：失效、时间、分批、跟踪
 11. 棘轮；落盘记忆
```

实盘执行必须是 **事件驱动 + 轮询**：公告/上币推送不能等下一根 15m K。  
纸上模式用 15m 验证「选标的和风控」是否在统计上说得通。

## 12. 纸上市场里种下的「别人会怎么死」

引擎自带可复现的纸上宇宙，用来打逻辑，不是用来吹回测曲线：

| 事件 | 别人常见动作 | 我们应有动作 |
|---|---|---|
| 缩簧后三族共振再暴涨 | 没盯过这币，追在 40% 之后 | 预先 ARMED，点火即进，分批让利润跑 |
| 单独放量假突破 | 当成「放量突破」追 | 不足三族 → 忽略 |
| 抛物线 + 解锁 + 充币 | 还在抄底 | 1x 空命题 |
| 龙头先涨、滞后币仍缩簧 | 加仓龙头 | 买滞后币 |
| BTC 暴跌日的山寨点火 | 照样做多山寨 | 体制过滤拒绝 |

纸上赚到钱 **不证明** 实盘能 100x。它只证明：门控、止损、不追拥挤，这些逻辑是闭合的。

## 15. 成功长什么样（过程指标，不是口号）

半年后先看这些，再看有没有 100x：

1. 空仓时间是否真的占绝对多数。
2. 假突破是否大多在 5% 权益以内被杀掉。
3. 少数赢家是否拿到过 >100% 的命题级回报（而不是 8% 就跑）。
4. 金库是否在权益翻倍时真的锁过。
5. 记忆里是否出现过稳定的「肥尾共振组合」。

没有前四条，第五条和 100x 都是幻觉。
